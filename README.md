A flight game that runs in a desktop browser from static files — no build
step, no network requests. Open `game/index.html` through any static file
server and fly with keyboard and mouse.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 in a desktop browser.

To produce the hand-in output (the game, the screenshots and
`dossier.json`) the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
